## 📖 故事

一次争吵之后，母女跌进了一座废弃的中转站。

检票机吐出两张票——每张票，都通向对方的人生。

- **女儿的票**：《纸燕子的最后一天》
- **母亲的票**：《永远差一圈的兔子》

走完了，把带回来的东西放在长椅上。

## ✨ 核心设计

**你玩的从来不是自己**
第一章你是女儿，但你走的是母亲十八岁那天。她那个"只知道求稳"的人生，是一天之内被病床、工资袋和 16:40 的检票口一点点拿走的——这不是台词能达成的理解，是你自己撕掉纸燕子翅膀换来的。

**算不完的一天**
第一章故意无解。赶上火车就顾不上家，顾上家就赶不上车。玩家必须亲身撞上"她当年没有完美选项"这件事。

**乌龟是"应该成为的自己"**
第二章那只永远快一圈的乌龟，龟壳磨得像面镜子。她追的从来不是别人家的孩子——摘下号码牌离场时，游戏给的出口是：追不上就追不上吧，跟她道个别，然后回家吃饭。

**同一个手势，三种心境**
「夹虾」这个拖拽动作出现三次：序章是替她做主，结局是一人一半，多年以后是女儿差点重复同一句话。

**推门与敲门**
开场母亲不敲门直接推开女儿的房门；结局她抬手、停住、改成敲门。整个游戏就是为了这一个动作。

**重复的一天会褪色**
第一章每重走一次，场景里的人就淡一层，红星小学老师的脸越来越模糊。机制本身在说"记忆在消失"。

**拒绝廉价和解**
母亲没有变成理想家长，女儿也没有放弃离开。她们只是第一次承认：母亲的担心可以存在，但不再自动成为命令；女儿的边界可以存在，但不再必须通过消失建立。

## 🤖 AI 能力

游戏中的守站人「年伯」由大语言模型实时驱动，共三处：

| 能力 | 说明 |
|---|---|
| **自由对话** | 玩家可在中转站、第一章旧电话、彩蛋末班电话随时向年伯提问任意内容，AI 结合当前剧情进度实时回应 |
| **票背留言** | 通关后，AI 依据玩家在两个副本中的真实选择，生成一段专属的车票背面留言 |
| **结局分支判定** | 余味段落玩家输入一句话，由 AI 判读语义，决定进入哪条结局 |

**人设约束**：通过系统提示词固化「见证者而非导师」的角色边界——不说教、不评判母女谁对谁错、不剧透、不替玩家做选择、身份永不点破。

### ⚠️ 可靠性设计

> **AI 只增强表达，绝不影响游戏进程。**

一旦模型超时（8 秒）、报错或未配置，系统立即回退到本地预置文案，状态码始终 200。**章节完成、解锁、存档与固定结局完全不依赖 AI**，玩家全程无感知。
